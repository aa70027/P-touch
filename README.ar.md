# دليل استوديو ملصقات الكابلات — ١٫٢٫١

## قيد التطوير: حالة الطباعة في Excel الأصلي

توجد هذه الميزة في شفرة التطوير وليست ضمن المثبّت العام ١٫٢٫١. افتح مصادر البيانات ← حالة الطباعة في Excel واختر ملف XLSX/XLSM أصلياً تملكه ومرتبطاً عبر اختيار ملف Windows. لا تعدّل النسخة المرفوعة الملف الأصلي. يلزم عمود معرّف ثابت وفريد داخل كل ورقة وعمود حالة نصي، مثل `RecordID` و`PrintStatus`. حدّد الأوراق والأعمدة واقرأ السجلات، ثم عيّن `OK` أو أدخل قيمة واحفظ في Excel الأصلي.

أغلق الملف في Excel قبل الكتابة. تتغيّر خلايا الحالة فقط مع نسخة احتياطية كاملة وسجل تغييرات ورابط تنزيل خاص بالمالك. تبقى الصيغ وبيانات VBA والصور وأجزاء الحزمة الأخرى محفوظة. تُرفض الأوراق المحمية والملفات الموقعة رقمياً والمعرّفات المكررة أو الفارغة أو المحسوبة وعمود الحالة ذي الصيغ. تغيّر الملف بعد القراءة يمنع العملية كاملة حتى إعادة القراءة والمراجعة. يلزم تحويل XLS القديم في Excel. لا يحسب التطبيق الصيغ التابعة؛ يعيد Excel حسابها عند فتح الملف.

تسجيل الحالة تأكيد يدوي؛ لا يجعل الإرسال أو المحاكاة الحالة `OK` تلقائياً. تعرض الواجهة أن الجهاز غير متزامن. نقل قالب PT-E550W الأصلي واسترجاع الخلايا المعدلة من الجهاز لم يُنفّذا أو يُتحقق منهما بعد. ليست نسخة Brother الاحتياطية تصديراً قابلاً للتحرير في Excel/CSV. تتطلب متابعة مسار الجهاز أدوات Brother الرسمية والاتصال بالجهاز أو نسخاً احتياطية حقيقية قبل تعديل خلية وبعده. يحتوي `examples/device-status-sample.csv` سجلين اصطناعيين للاختبار وليس نسخة فعلية من الجهاز.

## إصلاح أوامر القطع وإرسال USB في ١٫٢٫١ — ٢٠٢٦/١١/٢٧

يستخدم القطع الكامل الأخير تحكم نهاية السلسلة والتغذية والقطع المستقل. لا يفعّل اختيار القطع الكامل الأخير وضع القطع التلقائي لكل ملصق؛ يُرسل أمر القطع لكل ملصق فقط عند طلب قطع كامل بين الصفحات. ينطبق تعديل المرمّز المشترك على USB وWi-Fi.

كان إرسال RAW يفتح ويغلق صفحة Windows لكل ملصق. أزيلت هذه الحدود الإضافية؛ تُرسل النسخ المتواصلة في مستند RAW واحد باستخدام حدود صفحات Brother. يبقى توقف تأكيد السجل بداية مقطع جديد. يعالج هذا الإصلاح نقطة مشتبهة في مسار USB؛ تحديد سبب القطع الزائد المبلّغ عنه واعتماد النتيجة الفعلية يحتاجان اختبار الجهاز. يرسل مسار الشبكة خرج المرمّز المشترك عبر اتصال واحد.

لصفحة واحدة وسجل واحد وخمس نسخ: تكرار الصفحة في المصمم ١، ونسخ كل صفحة في نافذة الطباعة ٥، ونسخ كل ملف ١، والطباعة متواصلة، ونصف قطع بين الصفحات والنسخ، وقطع كامل في نهاية الملف الأخير. يتحقق الاختبار من أربع سياسات نصف قطع وقطع كامل أخير دون ادعاء اعتماد الإخراج الفعلي. يسجل السجل التقني سياسة القطع ورقم الصفحة وحدود المقطع ومعرّف قائمة Windows دون نص الملصق، ضمن الإعدادات ← سجلات التطبيق.

## الإصدار ١٫٢٫٠ — ٢٠٢٦/١١/٢٧

**قطع خاص بكل ملف:** تقرأ نافذة الطباعة الإعدادات العامة المحفوظة حالياً. يرثها الملف دون تخصيص، بينما يعرض الملف المخصص سياسته المحفوظة. يمكن تعديل الحدود الأربعة—بين الصفحات والتكرارات ونهاية السجل وبين الملفات ونهاية الملف—لكل ملف مختار داخل النافذة. يحفظ بدء الطباعة التغييرات لكل ملف. يعيد «استخدام الإعدادات العامة» الملف إلى وراثة الإعدادات الجديدة لاحقاً. تحتفظ المهمة بلقطة ثابتة فلا يغيّرها تعديل الإعدادات العامة أثناء العمل. عند حد الملف تُطبّق سياسة الملف المنتهي.

يحدّث حفظ قطع ملفك هذا الحقل فقط دون استبدال تعديلات التخطيط الأخرى. يُحفظ التصميم غير المحفوظ أو الملف المشترك المملوك لشخص آخر كنسخة خاصة عند تغيير القطع وإرسال الطباعة. يلغي إغلاق النافذة التغييرات غير المؤكدة. يبقى التحكم الفعلي بقاطع طرازات برنامج تشغيل Windows في خصائص Brother كما في الإصدارات السابقة.

**الأرقام الفارسية:** فعّل خيار عرض الأرقام الفارسية وطباعتها في خصائص الملصق. بعد ربط البيانات وتقييم الصيغ، تتحول الأرقام اللاتينية والعربية في النص المقروء إلى ۰۱۲۳۴۵۶۷۸۹ في المعاينة والطباعة معاً. لا تتغير قيم Excel أو القواعد أو بيانات QR والباركود. يُحفظ الخيار لكل صفحة في الملفات والقوالب والتصدير، ويعيد إلغاؤه الأرقام الأصلية.

**توسيط مقاس فعلياً:** يوفر قسم الموضع والحجم زر التوسيط عبر عرض الشريط للعنصر المختار، وزر التوسيط في الصفحة أو الخانة للمحورين. يشمل القياس النص والصور والدوران. يثبّت توسيط الصفحة الطول التلقائي الحالي كي لا يتغيّر المركز مجدداً بعد نقل المحتوى، مع تلميح يوضح ذلك. لا يغيّر توسيط العرض الطول التلقائي.

تتضمن رسالة تجاوز منطقة الطباعة زر نقل المحتوى إلى وسط عرض الشريط. ينقل المجموعة مع الحفاظ على المسافات النسبية. إذا تجاوز ارتفاع المحتوى أو الإطار المنطقة القابلة للطباعة، أو منعت الهوامش التوسيط، تظهر رسالة لإصلاح الأبعاد أو الهوامش دون تصغير أو قص صامت.

**الوجهة بعد الإرسال:** تقدم نافذة الطباعة زرين: صفحة قائمة الطباعة، أو البقاء في هذه الصفحة. يُحفظ الاختيار للمستخدم الحالي في المتصفح نفسه. يحافظ البقاء على المصمم والعنصر المختار، وتعرض رسالة صغيرة لخمس ثوان نجاح الإرسال أو اكتمال المحاكاة أو الفشل أو الإلغاء. لا يعني نجاح الإرسال تأكيد الإخراج الفعلي. تتوفر الحالة المباشرة والإلغاء وتأكيد السجل التالي داخل المصمم. لا تعيد محاولة اتصال الحالة إرسال بيانات الطباعة.

استخدم `CableLabelStudio-1.2.1-Setup.exe` للتثبيت والترقية، أو أداة التحديث المصححة. يتضمن الإصدار إصلاح HTTPS السابق؛ يمكن لمستخدمي ١٫١٫٠ المتأثرين الترقية اليدوية مباشرة إلى ١٫٢٫٠.

في وضع تأكيد كل سجل، استخدم زر السجل التالي داخل المصمم أو الاختصار `Ctrl+Enter`. بعد التحديث من داخل التطبيق، حدّث صفحة المتصفح مرة واحدة باستخدام `F5` لتحميل الواجهة الجديدة.


## إصلاح خطأ التحديث في ١٫١٫١ — ٢٠٢٦/١١/١٨

أغفلت حزمة Windows للإصدار ١٫١٫٠ ملف سياسة شهادات PEM المطلوب لمكتبة HTTPS. لذلك فشل إنشاء الاتصال الآمن بخطأ `[Errno 2] No such file or directory` قبل الاتصال بـ GitHub. تتضمن حزمة ١٫١٫١ الملف المطلوب مع بقاء التحقق من الشهادة واسم المضيف مفعّلاً. أضيف اختبار HTTPS حقيقي من الملف التنفيذي إلى اختبارات الإصدار. تعرض صفحة التحديث نوع الخطأ ومرحلة العملية والتقرير التقني المحفوظ.

إذا تعذر فحص الإصدارات في ١٫١٫٠ بهذا الخطأ، **نزّل مثبّت ١٫٢٫١ الحالي يدوياً مرة واحدة وشغّل الترقية**؛ تُحفظ بيانات المستخدم. يمكن فحص التحديثات اللاحقة وتنزيلها عبر الأداة المصححة. ليست إعدادات الطابعة أو ملفات الملصقات سبب الخطأ.

تطبيق Windows يعمل دون اتصال، بواجهة داخل المتصفح، لتصميم ملصقات Brother PT-E550W وإرسالها للطباعة. تُحفظ القوالب والملفات والحسابات والبيانات والتقارير على الحاسوب نفسه.

## التثبيت والتشغيل

شغّل `CableLabelStudio-1.2.1-Setup.exe` واختر العربية أو الفارسية أو الإنجليزية. اختر تثبيتاً جديداً ومجلداً مخصصاً للتطبيق. يعرض المعالج تقدم العملية والتحقق من SHA-256 وسجل التثبيت المحفوظ. بعد التثبيت شغّل اختصار سطح المكتب أو قائمة Start. العنوان الافتراضي `http://127.0.0.1:8765` ولا تلزم كلمة مرور في البداية.

الحزمة مخصصة لـ Windows 10/11 بنسخة ٦٤ بت، وتتضمن Python. يستخدم المعالج .NET Framework 4.7.2 أو أحدث. التثبيت للمستخدم الحالي؛ قد يحتاج اختيار مجلد محمي إلى صلاحيات Windows مناسبة. يستمع التطبيق إلى العنوان المحلي فقط، ولا يُنشر على الشبكة المحلية.

أعد تشغيل المثبّت أو اختصار Maintenance للإصلاح أو التحديث أو الإزالة. يعيد الإصلاح ملفات البرنامج من الحزمة. للتحديث شغّل مثبّت الإصدار الأحدث. تُستعاد ملفات الإصدار السابق إذا فشل استبدالها. تظل بيانات المستخدم منفصلة ومحفوظة عند الإصلاح والتحديث والإزالة. يمكن تشغيل النسخة المحمولة باستخراج ZIP وتشغيل `CableLabelStudio.exe`.

## الاتصال بالطابعة

في الإعدادات اختر USB وطابعة Brother PT-E550W المثبتة، أو Wi-Fi وعنوان IP ومنفذ TCP، افتراضياً ٩١٠٠. يحتاج USB إلى برنامج Brother الرسمي. يُرفض إرسال الأوامر الخام إلى طرازات أخرى. تغيير عنوان IP في التطبيق يغيّر وجهة الاتصال ولا يغيّر إعداد شبكة الطابعة نفسها.

تثبيت برنامج التشغيل ووجود جهاز USB وحالة قائمة Windows والوصول إلى منفذ الشبكة مؤشرات منفصلة. الوصول إلى المنفذ لا يثبت جاهزية الشريط أو اكتمال الطباعة الفعلية.

## التصميم والأبعاد

التخطيطات: عام، علم كابل، لف كابل، لوحة توصيل، لوحة واجهة، تخطيط علم مقصوص، وكتلة توصيل. تخطيط الأنبوب الحراري متاح للمحاكاة؛ تتوقف طباعة HSe الفعلية حتى اعتماد ملف الشريط المناسب.

اختر عرض شريط TZe الموجود فعلياً: ٣٫٥ أو ٦ أو ٩ أو ١٢ أو ١٨ أو ٢٤ مم. المنطقة القابلة للطباعة على شريط ٢٤ مم نحو ١٨ مم. يرفض البرنامج العناصر الخارجة عن المنطقة قبل إدراج المهمة في القائمة.

الطول يدوي أو تلقائي حسب النص، وقد يختلف بين السجلات. يشمل الطول المطلوب هامشاً ميكانيكياً أدناه ٢ مم لكل طرف. يمكن إزالة المسافة الاختيارية قبل النص وبعده، لكن لا يمكن إزالة الهامش الميكانيكي. قد يبلغ إخراج ملصق منفرد قصير ٢٤٫٥ مم بسبب موقع القاطع. مجال طول التخطيط ٤٫٤–١٠٠٠ مم. تعرض المعاينة تقديراً منفصلاً للإخراج المنفرد.

الجودة القياسية ١٨٠×١٨٠ والعالية ١٨٠×٣٦٠ نقطة في البوصة، مع زيادة دقة محور واحد. الطباعة المعكوسة تعكس الصورة النهائية مرة واحدة. يلزم اختبار الجهاز للتحقق من الأبعاد الفعلية والقطع لكل شريط وبرنامج ثابت.

يمكن إضافة نصوص وصور وخطوط وإطارات وQR وCode 128. يمكن تعديل الخط وحجمه والعرض والتسطير والمحاذاة والاتجاه والدوران. تُعالَج الوصلات العربية والفارسية واتجاهات النص المختلطة قبل إنشاء صورة الطباعة. اختر خطاً يتضمن الأحرف المطلوبة. يدعم Code 128 أحرف ASCII؛ استخدم QR للنص العربي والفارسي.

حرّك العناصر بالفأرة أو حقول X/Y/W/H بالملليمتر. الأسهم تحرّك العنصر ٠٫١ مم وShift مع الأسهم ١ مم. العرض صفر يلائم النص تلقائياً. عند تجاوز النص الإطار، زد أبعاد الإطار أو صغّر الخط؛ لا يُقص النص بصمت.

يعيد علم الكابل البيانات نفسها على الطرفين من حقل واحد. يمكن ضبط الفجوة والنص الفاصل والخط. لف الكابل يكرر النص عمودياً. تستخدم لوحة التوصيل وكتلة التوصيل عدد الخانات وتباعدها، ويعطي `{#cell}` رقم الخانة بدءاً من ١. تخطيط Die-cut Flag يُطبع على شريط متواصل؛ لا ينشئ القاطع شكلاً مقصوصاً خاصاً.

في تخطيط العلم يحدد الطول اليدوي طول كل جانب، وتعرض المعاينة طول الطرفين مع الفجوة. يجب أن يتسع الطول اليدوي للوحة التوصيل أو كتلة التوصيل لكل الخانات والهامشين؛ تضيف الزيادة فراغاً نهائياً دون تغيير تباعد الخانات.

يمكن للملف احتواء صفحات متعددة، لكل منها تصميم وأبعاد وتكرار مستقل. احفظ الملف أو القالب في المكتبة. الاستيراد والتصدير بصيغة `.label.json` الخاصة بالمشروع؛ ملفات Brother الأصلية `.lbx` غير مدعومة. مجموعات البيانات مستقلة وتُختار عند الطباعة. تحفظ الملفات والقوالب التخطيط والقواعد والمتغيرات النموذجية.

## الصور والخطوط

ارفع صور PNG وJPG وJPEG وBMP وWEBP أو خطوط TTF وOTF في قسم الصور والخطوط، ثم اخترها في خصائص العنصر. تظل الملفات محفوظة بعد إغلاق التطبيق. حد كل ملف ٥٠ ميغابايت. استخدم موارد تملك حقوق استخدامها.

## Excel وCSV وAccess

ارفع XLSX أو XLSM أو XLS أو CSV أو TSV أو MDB أو ACCDB. اختر ورقة أو عدة أوراق، أو جدول Access والترميز والفاصل، ثم أعد قراءة المصدر. يحدد الصف الأول أسماء الأعمدة في الجداول النصية وExcel؛ تُعدّل الأسماء المكررة والفارغة لتصبح فريدة. تستخدم صيغ Excel القيم المحسوبة المحفوظة، لذا احسب الملف واحفظه في Excel قبل الاستيراد. لا تُشغّل وحدات الماكرو.

يتطلب MDB/ACCDB برنامج ODBC من Microsoft Access Database Engine أو Access Runtime بنسخة ٦٤ بت. يوضح التشخيص وجوده أو غيابه؛ لا يثبته التطبيق بصمت. يعمل Excel وCSV دون Access أو Office.

المصدر المرفوع نسخة محفوظة؛ ارفع الملف الأصلي مجدداً للحصول على التغييرات الخارجية. إعادة قراءة المصدر تعيد قراءة النسخة المحفوظة وفق الورقة أو الجدول المحدد. احفظ مجموعة البيانات واستخدمها في المصمم، واربط النص بـ `{Rack}` أو `{Port}` أو اسم العمود العربي المطابق. يتوفر إدخال مصفوفات JSON وتعديل السجلات. الحد ١٠٠ ألف سجل غير فارغ للمجموعة؛ يُرفض الأكبر دون اقتطاع. تعرض الشبكة معاينة محدودة، مع الاحتفاظ بكامل البيانات للطباعة والتصدير.

## القواعد والصيغ

تُنفذ القواعد بالترتيب. لكل قاعدة حقل ناتج وشرط وصيغة قيمة وقيمة اختيارية لحالة عدم تحقق الشرط. يمكن للقواعد اللاحقة استخدام نتائج السابقة. لطباعة A في العنصر B، اختر الناتج `B` والشرط `not EMPTY(COL("X"))` والقيمة `'A'`، ثم اجعل نص العنصر `{B}`.

```text
IF(EMPTY(COL("X")), "", "A")
CONCAT(COL("Rack"), "-", PAD(COL("Port"), 2))
COL("Type") == "Fiber"
CONTAINS(LOWER(COL("Description")), "fiber")
```

الدوال: `COL`, `IF`, `EMPTY`, `CONCAT`, `PAD`, `UPPER`, `LOWER`, `TRIM`, `TEXT`, `NUMBER`, `LEN`, `REPLACE`, `CONTAINS`, `ROUND`, `AND`, `OR`, `NOT`. تدعم العمليات الحسابية والمقارنات والشروط. تبدأ صيغة العنصر بـ `=`، وتُكتب الأقواس الحرفية `{{` و`}}`. يُمنع تنفيذ Python عشوائي أو الوصول إلى الملفات أو الحلقات.

## الطباعة والقطع

اختر عدد نسخ الصفحة ونسخ الملفات، وكل السجلات أو نطاقاً، وأي ملفات محفوظة إضافية. يُطبع التصميم الحالي أولاً ثم الملفات المحددة. يتضاعف تكرار الصفحة المحدد في خصائصها بعدد النسخ في نافذة الطباعة. تمر كل نسخة ملف عبر المستندات وسجلاتها بالترتيب.

الطباعة المتواصلة ترسل السجلات دون تأكيد يدوي. تأكيد كل سجل يحتفظ بالسجل التالي محلياً حتى الضغط على الزر أو Enter/Space في صفحة القائمة. التأكيد بعد إرسال السجل السابق، وليس بعد إشارة اكتمال فعلية من الجهاز. تكون سجلات USB المؤكدة مهام Windows منفصلة.

يمكن ضبط القطع الكامل أو النصف أو عدم القطع بين الصفحات/النسخ ونهاية السجل وبين الملفات ونهاية آخر ملف. الأولوية: نهاية المهمة، ثم حد الملف، ثم حد السجل، ثم الصفحة. قد يفرض الشريط والبرنامج الثابت قيوداً على النتيجة، لذا اختبر التركيبات بالشريط الفعلي.

المحاكاة خيار صريح ولا ترسل بيانات للطابعة. تنشئ PNG وPRN خاصاً بالطراز، ويمكن تنزيلها من تفاصيل المهمة. لا تزيد المحاكاة عداد الإرسال الفعلي. تُفحص جميع الصيغ والتخطيطات قبل إدراج المهمة. حد المهمة ١٠٠ ألف ملصق؛ قسّم العمليات الأكبر إلى دفعات.

الإلغاء يوقف الإرسال اللاحق؛ قد تستمر طباعة البيانات التي تسلمتها Windows أو الطابعة. لا يعاد الإرسال تلقائياً بعد خطأ اتصال. بعد انقطاع البرنامج تصبح المهمة «انقطعت» وتحتاج مراجعة لتجنب التكرار. يمكن إعادة طباعة طلب محفوظ بعد مراجعته.

## الحسابات والمشاركة

الحساب الأول local مشرف. حدّد اسمه وكلمة مروره من الملف الشخصي ثم فعّل المصادقة في الإعدادات. الحد الأدنى ٨ أحرف وتُحفظ كلمات المرور كتجزئة Argon2. يلزم مشرف نشط بكلمة مرور قبل التفعيل. يحتفظ الحساب المدمج بصلاحية المشرف لوضع العمل دون تسجيل دخول.

لا يوجد سقف تعاقدي لعدد المستخدمين؛ تعتمد القدرة العملية على الحاسوب. يدير المشرف الحسابات. لكل مستخدم إعداد مشاركة افتراضي للقوالب والملفات والصور والخطوط ومجموعات البيانات والمصادر. يمكن للعنصر تجاوز الافتراضي إلى «أنا فقط» أو «كل المستخدمين». يفتح الآخرون المورد المشترك كنسخة؛ المالك وحده يستبدل الأصل أو يحذفه.

يرى المشرف كل مهام الطباعة والتقارير المجمعة. يرى المستخدم العادي مهامه وتقاريره. لا تنكشف موارد التصميم الخاصة تلقائياً لمجرد أن مستخدماً آخر مشرف. تغيير كلمة المرور يبطل جلسات الحساب، وتغيير وضع المصادقة يبطل الجلسات القائمة.

## الإعدادات والسجلات والنسخ الاحتياطي

يمكن ضبط منفذ المتصفح واللغة الافتراضية وعرض الشريط والجودة ومهلة الطابعة وحفظ الأحداث والتشغيل عند دخول Windows. احفظ ثم أعد تشغيل التطبيق لتغيير المنفذ. يستخدم التشغيل التلقائي حساب Windows الحالي، وليس خدمة تعمل قبل تسجيل الدخول.

تفصل التقارير بين المطلوب والمرسل والمحاكى والفاشل والملغى والمنقطع لكل مستخدم وفترة، وتصدر CSV. يبقى عداد تأكيد الطابعة مستقلاً ولا يزيد دون إشارة موثوقة.

المجلد `%LOCALAPPDATA%\CableLabelStudio` يحتفظ بالبيانات، و`logs` بالسجلات. تعرض الإعدادات سجل النشاط والسجل التقني. تنزّل النسخة الاحتياطية الكاملة ZIP يحتوي SQLite والملفات المرفوعة. للاستعادة أوقف التطبيق، وانسخ الحالة الحالية احتياطياً، ثم استخرج ZIP في مجلد البيانات. النسخ تشمل تجزئات الحسابات وبيانات الطباعة، فاحفظها بمكان مناسب.

## حالة التحقق

راجع `ACCEPTANCE.md`. لم تتوفر طابعة PT-E550W أو برنامج Brother على جهاز البناء. يلزم اختبار USB وWi-Fi والأبعاد والقطع والجودة العالية مع الجهاز الفعلي. يحتاج Access إلى اختبار بقاعدة حقيقية وبرنامج التشغيل المناسب. لا تُعرض المحاكاة أو تسليم المهمة إلى القائمة كطباعة فعلية مؤكدة.

### التثبيت والتحديث عبر الإنترنت

أول سؤال في المعالج هو «زبان را انتخاب کنید / Select your language / اختر لغتك»، مع ثلاثة أزرار ظاهرة معاً: فارسی وEnglish والعربية. لا تظهر أسئلة العملية والمسار قبل اختيار اللغة. تتوفر عمليات التثبيت الجديد والإصلاح والتحديث والإزالة والمسار المخصص. يعرض خيار اكتشاف طابعات Brother في المثبّت أجهزة USB بصورة مستقلة عن قوائم الطباعة وبرامج التشغيل. تحتفظ الصيانة ببيانات المستخدم.

افتح الإعدادات ← التحديثات والتنزيلات وافحص إصدارات GitHub. تعرض الصفحة نفسها الإصدار الحالي والجديد والتنزيل والتثبيت والتقدم والأحداث والأخطاء وسجل المثبّت المحفوظ. الإصدارات التجريبية اختيارية؛ احفظ الخيار أو اضغط الفحص لتطبيقه. يتطلب التثبيت عبر الإنترنت حزمة Windows المثبّتة. يُنزَّل التحديث من Releases لهذا المشروع ويُفحص SHA-256 قبل التثبيت. هذا تحقق من سلامة النقل وليس توقيعاً رقمياً للناشر. تُنشأ نسخة احتياطية للقاعدة قبل التثبيت؛ يعيد المثبّت ملفات التطبيق السابقة إذا فشل النسخ. تمنع مهام الطباعة النشطة التثبيت. تتوقف الخدمة المحلية مؤقتاً وتعيد الصفحة الاتصال تلقائياً لعرض النتيجة والسجل. استخدم المثبّت غير المتصل إذا تعذّر التحديث عبر الإنترنت.

### Excel متعدد الأوراق ومسار Windows مباشر

في مصادر البيانات ارفع مصنفاً أو اختر «ربط ملف Excel من Windows» لفتح مربع اختيار الملفات الحقيقي. يُحفظ مسار الملف الأصلي خصوصياً دون رفع نسخة. تظهر جميع الأوراق كخيارات متعددة؛ اختر ورقة أو عدة أوراق واضغط إعادة قراءة المصدر. تُدمج الأعمدة المختلفة ويحفظ `_sheet` اسم ورقة كل سجل لاستخدامه في القواعد والنص. إذا كان الملف يتضمن عمود `_sheet` فيُحفظ محتواه الأصلي باسم `_sheet_value`. الحد الإجمالي ١٠٠٬٠٠٠ سجل مختار.

عدّل الملف في Excel ثم **احفظه**. تعيد المعاينة وإنشاء مهمة طباعة جديدة قراءة الملف الأصلي دون رفعه مجدداً. تحتفظ كل مهمة مسجّلة بلقطة ثابتة من البيانات الحديثة حتى لا تؤثر التغييرات اللاحقة في مهمة جارية. تعيد قراءة المصدر تحديث الجدول والعدد الظاهر. يوقف تحرير الخلايا يدوياً داخل التطبيق القراءات التلقائية حتى إعادة قراءة المصدر. غيّر المسار باختيار ملف جديد من Windows. ينتج عن حذف الملف أو منع الوصول أو القفل الحصري خطأ بدلاً من طباعة بيانات قديمة بصمت. لا تتوفر تغييرات Excel غير المحفوظة ولا يعيد التطبيق حساب صِيَغه؛ احفظ القيم المحسوبة أولاً. احفظ مجموعة بيانات للاحتفاظ بالربط. تتضمن النسخة الاحتياطية المسار دون محتوى الملف الخارجي؛ احتفظ بنسخة منفصلة منه.

### الاتصال والاكتشاف وعناوين IP المتغيرة

في الإعدادات ← الاتصال واكتشاف الطابعة، اضبط الطراز وUSB أو Wi-Fi وقائمة Windows وIP والمنفذ واسم الشبكة وMAC والنطاق المحلي، ثم احفظ قبل التحديد. يستخدم اكتشاف USB أسماء PnP ومعرّفات العتاد حتى دون برنامج تشغيل. حالة برنامج التشغيل وقائمة الطباعة منفصلة. يستخدم تحديد الطراز الشبكي SNMP للقراءة فقط؛ يبقى الطراز مجهولاً إذا كان SNMP معطلاً أو محجوباً. لا يؤكد منفذ TCP المتاح هوية الطابعة أو اكتمال الطباعة الفعلية.

يفضل اسم DNS ثابت للطابعة أو حجز DHCP في الموجّه. ويمكن إدخال **MAC اللاسلكي** للطابعة وتفعيل البحث عن IP الحالي قبل الطباعة واختيار نطاق المحول المحلي. يعرض البحث تقدمه ومرشحي IP وMAC والطراز؛ اختر النتيجة الصحيحة واحفظها. يُعاد الحل قبل بدء المهمة أيضاً، ويمنع غياب MAC أو اختلافه الطباعة. يقتصر MAC على الوصلة المحلية نفسها؛ تحتاج الشبكات الموجّهة وVLAN المختلفة وعزل العملاء إلى DNS أو إعداد مناسب للموجّه. لا يقبل الاكتشاف إلا نطاق IPv4 محلياً مختاراً لا يزيد عن ١٠٢٤ عنواناً. لا تُعرض هوية غير معروفة كطراز مؤكد.

**الاتصال المباشر بـ PT-E550W:** اختر `Menu → WLAN → Network Mode → Direct Mode`. اعرض معلومات الشبكة وIP عبر `WLAN → Network Status → Direct Mode`، واقرأ SSID والمفتاح من الطابعة أو Printer Setting Tool الرسمي. افتح إعدادات Wi-Fi في Windows من التطبيق واتصل بشبكة الطابعة، ثم أدخل IP المعروض أو ابحث بواسطة MAC اللاسلكي. قد ينقطع الإنترنت عن الكمبيوتر؛ نزّل التحديث أولاً.

**عبر الموجّه:** اختر `Menu → WLAN → Network Mode → Infrastructure Mode` ثم `WLAN → Network Setting → Infrastructure Mode → Setup Wizard`. اختر SSID للموجّه وأدخل مفتاحه على الطابعة. صِل الكمبيوتر بالموجّه نفسه عبر Ethernet أو Wi-Fi. تجنب شبكة الضيوف وعزل العملاء. احفظ اسم الشبكة أو IP وMAC في التطبيق. لا يجمع التطبيق كلمة مرور Wi-Fi ولا يعيد إعداد الطابعة بصمت. لا يعمل وضعا Direct وInfrastructure معاً في E550W.

### الطرازات الأخرى والتنزيل الرسمي

تتوفر ملفات Raster موثقة لـ PT-E550W وPT-P750W وPT-P710BT. يدعم E550W/P750W عبر الملف USB وWi-Fi والقطع الكامل والنصفي وبدون قطع. يستخدم P710BT اتصال USB هنا والقطع الكامل أو بدون قطع، ولا يدعم Wi-Fi أو نصف القطع. تدعم هذه المجموعة أشرطة TZe من ٣٫٥ إلى ٢٤ مم وعرض ١٨٠×١٨٠ أو ١٨٠×٣٦٠.

تستخدم PT-P700 وPT-P900W وPT-P950NW وQL-800 وQL-810W وQL-820NWB برنامج Brother الرسمي المثبّت في Windows مع قائمة USB أو شبكة. يعرض P900/P950 حتى ٣٦ مم بدقة ٣٦٠×٣٦٠ أو ٣٦٠×٧٢٠، وطرازات QL المذكورة حتى ٦٢ مم بدقة ٣٠٠×٣٠٠ أو ٣٠٠×٦٠٠. يسمح ملف Brother Windows driver العام بطرازات أخرى بعد ضبط وسائطها الفعلية والتحقق منها في برنامج التشغيل. يتحكم برنامج التشغيل بخصائص الوسائط والاتجاه والجودة النهائية والقاطع؛ لا تحول سياسات القطع في التطبيق إلى أوامر RAW لهذه المجموعة. تُرفض الأبعاد غير المتوافقة بدلاً من تغيير المقياس سراً. لا يتوفر RAW المباشر عبر Wi-Fi دون برنامج تشغيل لهذه المجموعة. محاكاتها PNG؛ وتتوفر PRN لملفات Raster فقط.

اختر الطراز في التحديثات والتنزيلات وافتح صفحته الرسمية لدى Brother. حدد Windows والبرنامج في الموقع ثم الصق رابط ملف `.exe` أو `.msi` أو `.zip` المباشر في التطبيق. تعرض الصفحة نفسها التقدم والأخطاء والملف وSHA-256. تُقبل روابط HTTPS على brother.com ونطاقاته الفرعية فقط. افتح الملف المنزّل لتثبيته؛ لا تُشغّل برامج التشغيل تلقائياً. تتحكم Brother بإصدارات برامجها وشروط تراخيصها.

لا تعني اختبارات البرنامج والمحاكاة اعتماد طابعة فعلية. يلزم اختبار الإخراج والأبعاد والوسائط الخاصة والقطع والدقة لكل جهاز. يحتاج Access إلى برنامج ODBC المناسب ٦٤ بت واختبار قاعدة فعلية. راجع [ACCEPTANCE.md](ACCEPTANCE.md) و[NEXT_UPDATE.md](NEXT_UPDATE.md).
