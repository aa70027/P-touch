# دليل استوديو ملصقات الكابلات — ١٫٠٫٠

تطبيق Windows يعمل دون اتصال، بواجهة داخل المتصفح، لتصميم ملصقات Brother PT-E550W وإرسالها للطباعة. تُحفظ القوالب والملفات والحسابات والبيانات والتقارير على الحاسوب نفسه.

## التثبيت والتشغيل

شغّل `CableLabelStudio-1.0.0-Setup.exe` واختر العربية أو الفارسية أو الإنجليزية. اختر تثبيتاً جديداً ومجلداً مخصصاً للتطبيق. يعرض المعالج تقدم العملية والتحقق من SHA-256 وسجل التثبيت المحفوظ. بعد التثبيت شغّل اختصار سطح المكتب أو قائمة Start. العنوان الافتراضي `http://127.0.0.1:8765` ولا تلزم كلمة مرور في البداية.

الحزمة مخصصة لـ Windows 10/11 بنسخة ٦٤ بت، وتتضمن Python. يستخدم المعالج .NET Framework 4.7.2 أو أحدث. التثبيت للمستخدم الحالي؛ قد يحتاج اختيار مجلد محمي إلى صلاحيات Windows مناسبة. يستمع التطبيق إلى العنوان المحلي فقط، ولا يُنشر على الشبكة المحلية.

أعد تشغيل المثبّت أو اختصار Maintenance للإصلاح أو التحديث أو الإزالة. يعيد الإصلاح ملفات البرنامج من الحزمة. للتحديث شغّل مثبّت الإصدار الأحدث. تُستعاد ملفات الإصدار السابق إذا فشل استبدالها. تظل بيانات المستخدم منفصلة ومحفوظة عند الإصلاح والتحديث والإزالة. يمكن تشغيل النسخة المحمولة باستخراج ZIP وتشغيل `CableLabelStudio.exe`.

## الاتصال بالطابعة

في الإعدادات اختر USB وطابعة Brother PT-E550W المثبتة، أو Wi-Fi وعنوان IP ومنفذ TCP، افتراضياً ٩١٠٠. يحتاج USB إلى برنامج Brother الرسمي. يُرفض إرسال الأوامر الخام إلى طرازات أخرى. تغيير عنوان IP في التطبيق يغيّر وجهة الاتصال ولا يغيّر إعداد شبكة الطابعة نفسها.

تثبيت برنامج التشغيل ووجود جهاز USB وحالة قائمة Windows والوصول إلى منفذ الشبكة مؤشرات منفصلة. الوصول إلى المنفذ لا يثبت جاهزية الشريط أو اكتمال الطباعة الفعلية.

[تنزيلات Brother الرسمية](https://support.brother.com/g/b/downloadtop.aspx?c=us&lang=en&prod=e550weus)

## التصميم والأبعاد

التخطيطات: عام، علم كابل، لف كابل، لوحة توصيل، لوحة واجهة، تخطيط علم مقصوص، وكتلة توصيل. تخطيط الأنبوب الحراري متاح للمحاكاة؛ تتوقف طباعة HSe الفعلية حتى اعتماد ملف الشريط المناسب.

اختر عرض شريط TZe الموجود فعلياً: ٣٫٥ أو ٦ أو ٩ أو ١٢ أو ١٨ أو ٢٤ مم. المنطقة القابلة للطباعة على شريط ٢٤ مم نحو ١٨ مم. يرفض البرنامج العناصر الخارجة عن المنطقة قبل إدراج المهمة في القائمة.

الطول يدوي أو تلقائي حسب النص، وقد يختلف بين السجلات. يشمل الطول المطلوب هامشاً ميكانيكياً أدناه ٢ مم لكل طرف. يمكن إزالة المسافة الاختيارية قبل النص وبعده، لكن لا يمكن إزالة الهامش الميكانيكي. قد يبلغ إخراج ملصق منفرد قصير ٢٤٫٥ مم بسبب موقع القاطع. مجال طول التخطيط ٤٫٤–١٠٠٠ مم. تعرض المعاينة تقديراً منفصلاً للإخراج المنفرد.

الجودة القياسية ١٨٠×١٨٠ والعالية ١٨٠×٣٦٠ نقطة في البوصة، مع زيادة دقة محور واحد. الطباعة المعكوسة تعكس الصورة النهائية مرة واحدة. يلزم اختبار الجهاز للتحقق من الأبعاد الفعلية والقطع لكل شريط وبرنامج ثابت.

يمكن إضافة نصوص وصور وخطوط وإطارات وQR وCode 128. يمكن تعديل الخط وحجمه والعرض والتسطير والمحاذاة والاتجاه والدوران. تُعالَج الوصلات العربية والفارسية واتجاهات النص المختلطة قبل إنشاء صورة الطباعة. اختر خطاً يتضمن الأحرف المطلوبة. يدعم Code 128 أحرف ASCII؛ استخدم QR للنص العربي والفارسي.

حرّك العناصر بالفأرة أو حقول X/Y/W/H بالملليمتر. الأسهم تحرّك العنصر ٠٫١ مم وShift مع الأسهم ١ مم. العرض صفر يلائم النص تلقائياً. عند تجاوز النص الإطار، زد أبعاد الإطار أو صغّر الخط؛ لا يُقص النص بصمت.

يعيد علم الكابل البيانات نفسها على الطرفين من حقل واحد. يمكن ضبط الفجوة والنص الفاصل والخط. لف الكابل يكرر النص عمودياً. تستخدم لوحة التوصيل وكتلة التوصيل عدد الخانات وتباعدها، ويعطي `{#cell}` رقم الخانة بدءاً من ١. تخطيط Die-cut Flag يُطبع على شريط متواصل؛ لا ينشئ القاطع شكلاً مقصوصاً خاصاً.

في تخطيط العلم يحدد الطول اليدوي طول كل جانب، وتعرض المعاينة طول الطرفين مع الفجوة. يجب أن يتسع الطول اليدوي للوحة التوصيل أو كتلة التوصيل لكل الخانات والهامشين؛ تضيف الزيادة فراغاً نهائياً دون تغيير تباعد الخانات.

يمكن للملف احتواء صفحات متعددة، لكل منها تصميم وأبعاد وتكرار مستقل. احفظ الملف أو القالب في المكتبة. الاستيراد والتصدير بصيغة `.label.json` الخاصة بالمشروع؛ ملفات Brother الأصلية `.lbx` غير مدعومة. مجموعات البيانات مستقلة وتُختار عند الطباعة. تحفظ الملفات والقوالب التخطيط والقواعد والمتغيرات النموذجية.

## الصور والخطوط

ارفع صور PNG وJPG وJPEG وBMP وWEBP أو خطوط TTF وOTF في قسم الصور والخطوط، ثم اخترها في خصائص العنصر. تظل الملفات محفوظة بعد إغلاق التطبيق. حد كل ملف ٥٠ ميغابايت. استخدم موارد تملك حقوق استخدامها.

## Excel وCSV وAccess

ارفع XLSX أو XLSM أو XLS أو CSV أو TSV أو MDB أو ACCDB. اختر ورقة العمل أو جدول Access والترميز والفاصل، ثم أعد قراءة المصدر. يحدد الصف الأول أسماء الأعمدة في الجداول النصية وExcel؛ تُعدّل الأسماء المكررة والفارغة لتصبح فريدة. تستخدم صيغ Excel القيم المحسوبة المحفوظة، لذا احسب الملف واحفظه في Excel قبل الاستيراد. لا تُشغّل وحدات الماكرو.

يتطلب MDB/ACCDB برنامج ODBC من Microsoft Access Database Engine أو Access Runtime بنسخة ٦٤ بت. يوضح التشخيص وجوده أو غيابه؛ لا يثبته التطبيق بصمت. يعمل Excel وCSV دون Access أو Office.

المصدر المرفوع نسخة محفوظة؛ ارفع الملف الأصلي مجدداً للحصول على التغييرات الخارجية. إعادة قراءة المصدر تعيد قراءة النسخة المحفوظة وفق الورقة أو الجدول المحدد. احفظ مجموعة البيانات واستخدمها في المصمم، واربط النص بـ `{Rack}` أو `{Port}` أو اسم العمود العربي المطابق. يتوفر إدخال مصفوفات JSON وتعديل السجلات. الحد ١٠٠ ألف سجل غير فارغ للمجموعة؛ يُرفض الأكبر دون اقتطاع. تعرض الشبكة معاينة محدودة، مع الاحتفاظ بكامل البيانات للطباعة والتصدير.

## القواعد والصيغ

تُنفذ القواعد بالترتيب. لكل قاعدة حقل ناتج وشرط وصيغة قيمة وقيمة اختيارية لحالة عدم تحقق الشرط. يمكن للقواعد اللاحقة استخدام نتائج السابقة. لطباعة A في العنصر B، اختر الناتج `B` والشرط `not EMPTY(COL("X"))` والقيمة `'A'`، ثم اجعل نص العنصر `{B}`.

```text
IF(EMPTY(COL("X")), "", "A")
CONCAT(COL("Rack"), "-", PAD(COL("Port"), 2))
COL("Type") == "Fiber"
CONTAINS(LOWER(COL("Description")), "fiber")
```

الدوال: `COL`, `IF`, `EMPTY`, `CONCAT`, `PAD`, `UPPER`, `LOWER`, `TRIM`, `TEXT`, `NUMBER`, `LEN`, `REPLACE`, `CONTAINS`, `ROUND`, `AND`, `OR`, `NOT`. تدعم العمليات الحسابية والمقارنات والشروط. تبدأ صيغة العنصر بـ `=`، وتُكتب الأقواس الحرفية `{{` و`}}`. يُمنع تنفيذ Python عشوائي أو الوصول إلى الملفات أو الحلقات.

## الطباعة والقطع

اختر عدد نسخ الصفحة ونسخ الملفات، وكل السجلات أو نطاقاً، وأي ملفات محفوظة إضافية. يُطبع التصميم الحالي أولاً ثم الملفات المحددة. يتضاعف تكرار الصفحة المحدد في خصائصها بعدد النسخ في نافذة الطباعة. تمر كل نسخة ملف عبر المستندات وسجلاتها بالترتيب.

الطباعة المتواصلة ترسل السجلات دون تأكيد يدوي. تأكيد كل سجل يحتفظ بالسجل التالي محلياً حتى الضغط على الزر أو Enter/Space في صفحة القائمة. التأكيد بعد إرسال السجل السابق، وليس بعد إشارة اكتمال فعلية من الجهاز. تكون سجلات USB المؤكدة مهام Windows منفصلة.

يمكن ضبط القطع الكامل أو النصف أو عدم القطع بين الصفحات/النسخ ونهاية السجل وبين الملفات ونهاية آخر ملف. الأولوية: نهاية المهمة، ثم حد الملف، ثم حد السجل، ثم الصفحة. قد يفرض الشريط والبرنامج الثابت قيوداً على النتيجة، لذا اختبر التركيبات بالشريط الفعلي.

المحاكاة خيار صريح ولا ترسل بيانات للطابعة. تنشئ PNG وPRN خاصاً بالطراز، ويمكن تنزيلها من تفاصيل المهمة. لا تزيد المحاكاة عداد الإرسال الفعلي. تُفحص جميع الصيغ والتخطيطات قبل إدراج المهمة. حد المهمة ١٠٠ ألف ملصق؛ قسّم العمليات الأكبر إلى دفعات.

الإلغاء يوقف الإرسال اللاحق؛ قد تستمر طباعة البيانات التي تسلمتها Windows أو الطابعة. لا يعاد الإرسال تلقائياً بعد خطأ اتصال. بعد انقطاع البرنامج تصبح المهمة «انقطعت» وتحتاج مراجعة لتجنب التكرار. يمكن إعادة طباعة طلب محفوظ بعد مراجعته.

## الحسابات والمشاركة

الحساب الأول local مشرف. حدّد اسمه وكلمة مروره من الملف الشخصي ثم فعّل المصادقة في الإعدادات. الحد الأدنى ٨ أحرف وتُحفظ كلمات المرور كتجزئة Argon2. يلزم مشرف نشط بكلمة مرور قبل التفعيل. يحتفظ الحساب المدمج بصلاحية المشرف لوضع العمل دون تسجيل دخول.

لا يوجد سقف تعاقدي لعدد المستخدمين؛ تعتمد القدرة العملية على الحاسوب. يدير المشرف الحسابات. لكل مستخدم إعداد مشاركة افتراضي للقوالب والملفات والصور والخطوط ومجموعات البيانات والمصادر. يمكن للعنصر تجاوز الافتراضي إلى «أنا فقط» أو «كل المستخدمين». يفتح الآخرون المورد المشترك كنسخة؛ المالك وحده يستبدل الأصل أو يحذفه.

يرى المشرف كل مهام الطباعة والتقارير المجمعة. يرى المستخدم العادي مهامه وتقاريره. لا تنكشف موارد التصميم الخاصة تلقائياً لمجرد أن مستخدماً آخر مشرف. تغيير كلمة المرور يبطل جلسات الحساب، وتغيير وضع المصادقة يبطل الجلسات القائمة.

## الإعدادات والسجلات والنسخ الاحتياطي

يمكن ضبط منفذ المتصفح واللغة الافتراضية وعرض الشريط والجودة ومهلة الطابعة وحفظ الأحداث والتشغيل عند دخول Windows. احفظ ثم أعد تشغيل التطبيق لتغيير المنفذ. يستخدم التشغيل التلقائي حساب Windows الحالي، وليس خدمة تعمل قبل تسجيل الدخول.

تفصل التقارير بين المطلوب والمرسل والمحاكى والفاشل والملغى والمنقطع لكل مستخدم وفترة، وتصدر CSV. يبقى عداد تأكيد الطابعة مستقلاً ولا يزيد دون إشارة موثوقة.

المجلد `%LOCALAPPDATA%\CableLabelStudio` يحتفظ بالبيانات، و`logs` بالسجلات. تعرض الإعدادات سجل النشاط والسجل التقني. تنزّل النسخة الاحتياطية الكاملة ZIP يحتوي SQLite والملفات المرفوعة. للاستعادة أوقف التطبيق، وانسخ الحالة الحالية احتياطياً، ثم استخرج ZIP في مجلد البيانات. النسخ تشمل تجزئات الحسابات وبيانات الطباعة، فاحفظها بمكان مناسب.

## حالة التحقق

راجع `ACCEPTANCE.md`. لم تتوفر طابعة PT-E550W أو برنامج Brother على جهاز البناء. يلزم اختبار USB وWi-Fi والأبعاد والقطع والجودة العالية مع الجهاز الفعلي. يحتاج Access إلى اختبار بقاعدة حقيقية وبرنامج التشغيل المناسب. لا تُعرض المحاكاة أو تسليم المهمة إلى القائمة كطباعة فعلية مؤكدة.

## متطلبات التحديث التالي — سُجلت في ٢٠٢٦/١١/١٣

هذه المتطلبات الستة معتمدة للتحديث التالي، ولم تُضف بعد إلى الإصدار ١٫٠٫٠. تُحفظ قائمة المتابعة ومعايير القبول في [NEXT_UPDATE.md](NEXT_UPDATE.md).

1. **اختيار اللغة هو أول سؤال في المثبّت.** قبل أي سؤال أو خطوة أخرى، اعرض «زبان را انتخاب کنید / Select your language / اختر لغتك». اعرض «فارسی» و«English» و«العربية» معاً كثلاثة أزرار مستقلة، دون قائمة منسدلة. تستمر بقية خطوات المعالج باللغة المختارة.
2. **Excel متعدد الأوراق.** اكتشف جميع أوراق المصنف واعرضها، مع اختيار ورقة واحدة أو عدة أوراق وقراءة بياناتها للمعاينة وربط الحقول والطباعة، مع حفظ اسم الورقة لكل سجل. يدعم الإصدار الحالي اختيار ورقة واحدة وقراءتها؛ استيراد وطباعة عدة أوراق في عملية واحدة ضمن هذا التحديث.
3. **ربط مباشر بملف Excel في Windows.** إضافةً إلى الرفع، استخدم نافذة اختيار ملفات Windows لتحديد المسار الحقيقي وحفظه. اقرأ التغييرات المحفوظة من الملف نفسه عند التحديث وقبل الطباعة، دون إعادة الرفع. أتح تغيير المسار وأظهر أخطاء غياب الملف أو عدم الوصول أو قفله. التغييرات غير المحفوظة داخل Excel ليست موجودة بعد في ملف القرص.
4. **تحديث عبر الإنترنت من GitHub.** قارن الإصدار المثبّت بإصدارات مستودع المشروع الرسمي، واعرض وجود إصدار جديد وأتح تنزيل التحديث وتثبيته. أظهر التقدم والسجلات وتقرير النتيجة وأخطاء الفحص والتنزيل والتثبيت في صفحة التحديث نفسها، مع حفظ بيانات المستخدم.
5. **اكتشاف طراز الطابعة.** أضف اكتشاف طرازات Brother عبر USB وWi-Fi سواء ثُبّت برنامج التشغيل أم لا. اعرض الطراز وحالة برنامج التشغيل ونوع الاتصال بصورة منفصلة. استخدم المكوّن المحلي في Windows للعمليات المطلوبة؛ وعندما لا يكفي المتصفح وحده، وفّر خياراً/أداة اكتشاف في المثبّت. لا تعرض جهازاً يتعذر الوصول إليه كأنه مكتشف أو متصل.
6. **طرازات Brother الأخرى وتنزيل البرامج.** وسّع الدعم إلى طرازات ملصقات Brother الأخرى بملفات قدرات خاصة بكل طراز، تشمل عرض الشريط والدقة والقطع والاتصال. أضف اختيار الطراز وتنزيل برامج التشغيل والبرامج المتوافقة من مصادر Brother الرسمية، مع حالة التنزيل وأخطائه.

يجب تحديث الأدلة الفارسية والإنجليزية والعربية محلياً وعلى GitHub مع تنفيذ هذه المتطلبات، وإبقاؤها موسومة كمخططة حتى التنفيذ والتحقق.
